## Introduction

GitHub has recently updated the Copilot app and Copilot CLI to respect content exclusion policies configured by enterprise, organization, and repository administrators. This advancement improves how sensitive data is protected during AI-assisted coding.

## What Does This Mean?

Previously, Copilot might have used all files within a repository as context to generate code suggestions—even those containing sensitive information. Now, administrators can configure exclusion policies to prevent certain files from being used as context.

## Benefits for Developers and Organizations

- Enhanced privacy and security for sensitive files.
- Greater control over what Copilot accesses during suggestion generation.
- Alignment with organizational compliance and data protection standards.

## Conclusion

By incorporating content exclusions into the Copilot app and CLI, GitHub strengthens trust in AI-powered development tools and supports enterprise requirements for safeguarding proprietary or confidential content.
