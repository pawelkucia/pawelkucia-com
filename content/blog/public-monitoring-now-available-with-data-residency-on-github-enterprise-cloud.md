## Introduction
GitHub Enterprise Cloud (GHEC) now offers public monitoring with data residency in public preview. This extends the powerful secret scanning capabilities beyond internal repositories to the public domain.

## What Is Public Monitoring?
Public monitoring allows organizations to scan public repositories for leaked secrets, reducing the risk of unintentional exposure of sensitive information such as API keys, credentials, or tokens.

## Importance of Data Residency
Data residency ensures that sensitive data remains within specific geographic boundaries in compliance with local regulations. GitHub's solution respects these requirements while extending security coverage.

## Why It Matters
This update enables enterprises to maintain strong security postures and compliance simultaneously, protecting their assets across internal and public projects.

## Conclusion
Combining public monitoring with data residency support marks a significant advancement in secret scanning, helping organizations mitigate risks associated with secret leaks on public platforms.
