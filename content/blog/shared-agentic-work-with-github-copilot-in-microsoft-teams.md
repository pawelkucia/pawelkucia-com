## Bringing GitHub Copilot to Microsoft Teams

Microsoft Teams has taken a major leap in enhancing team collaboration by integrating GitHub Copilot directly into chat environments. This integration enables turning discussions into interactive, agent-powered sessions where all participants can collectively guide and contribute.

## How It Works

By mentioning @GitHub Copilot in a channel, thread, or direct message, users can initiate a shared agent session that everyone in the conversation can see. This setting fosters transparent collaboration, making it easier for teams to troubleshoot, co-develop, and share coding insights in real-time.

## Benefits for Teams

- Real-time collaborative coding support.
- Enhanced transparency in problem-solving.
- Easier onboarding and knowledge sharing.

This feature aligns with the growing trend of agentic work, empowering teams to work more cohesively and efficiently using AI assistance.
