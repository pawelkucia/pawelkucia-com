## Enhanced Credential Visibility for Enterprise Security

GitHub Enterprise has introduced a new feature enabling enterprise owners to export a comprehensive inventory of all credentials that have access to their enterprise environment. This includes SSH keys, both classic and fine-grained personal access tokens (PATs), OAuth App access tokens, and more.

## Why This Matters

With growing security challenges, maintaining visibility over who and what can access your enterprise assets is critical. This export functionality empowers organizations to perform thorough audits on all access credentials, enabling better risk assessments and tighter control over their security posture.

## What’s Included in the Export

- SSH keys
- Classic personal access tokens
- Fine-grained personal access tokens
- OAuth App access tokens

By consolidating access credentials into an exportable inventory, organizations can streamline their security reviews and respond faster to any unauthorized or suspicious access.

## Driving Stronger Security Practices

This update reflects GitHub’s ongoing commitment to enhancing enterprise security by providing practical tools that simplify credential management and compliance.
