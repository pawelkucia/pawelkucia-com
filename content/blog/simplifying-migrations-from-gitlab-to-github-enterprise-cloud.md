## New Migration Capabilities with GitHub Enterprise Importer

As organizations increasingly adapt their development workflows, migrating code repositories is a critical step. GitHub Enterprise Importer (GEI) now generally supports migrations from both GitLab.com and GitLab Self-Managed to GitHub Enterprise Cloud.

## Streamlining Your Migration Process

This enhancement means teams can perform self-serve migrations without extensive manual setup or third-party interventions, making the migration smoother and reducing downtime or errors.

## What This Means for DevOps Teams

Adopting GitHub Enterprise Cloud can offer integrated features and scalability. With GEI's extended support, transitioning existing projects from GitLab becomes more accessible, ensuring continuity and alignment with organizational goals.

Taking advantage of this tool can help minimize friction during platform changes and better position teams for future growth and collaboration efficiency.
