## New API Endpoints for Copilot Model Policies

GitHub has introduced new REST API endpoints that allow enterprises, teams, apps, and organizations to **retrieve and update** Copilot model policies programmatically. These endpoints support GET and PATCH HTTP methods, providing greater operational control.

## Why This Matters

Policy management is crucial when deploying AI tools at scale within businesses. The ability to adjust models' policies via API helps align AI behavior with corporate guidelines and compliance requirements without manual overhead.

## Streamlining AI Governance

This development enables organizations to integrate policy changes into automated workflows, making governance more consistent and adaptable. As AI models evolve, so can the policies governing their usage, maintaining responsible and efficient deployments.

## Final Thoughts

By exposing these REST API endpoints, GitHub empowers technical teams to efficiently manage AI integrations across their ecosystems, enhancing both control and agility in enterprise AI adoption.
