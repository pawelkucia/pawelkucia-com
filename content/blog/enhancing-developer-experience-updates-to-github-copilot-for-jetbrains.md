## Persistent Memory for Smarter Assistance

GitHub Copilot for JetBrains now supports persistent memory, allowing the AI assistant to retain context across multiple coding sessions. This change helps maintain continuity and reduces the need to repeat context, streamlining the coding process.

## Local Model Access Enhances Speed and Security

The update enables local model access, which means developers can rely on AI capabilities even without continuous internet connectivity. This also enhances data security, as sensitive code remains within the local environment.

## Strengthened Enterprise Controls

For organizations, Copilot's expanded enterprise controls provide more robust management and compliance options. This is crucial for meeting strict security and governance requirements.

## Improved Chat Workflows and Server Reliability

Daily interactions with Copilot are smoother thanks to refined chat workflows and the resolution of reliability issues across MCP servers. These improvements ensure a more stable and responsive user experience.

Together, these enhancements reflect GitHub's commitment to optimizing AI-driven coding tools for both individual developers and organizations.
