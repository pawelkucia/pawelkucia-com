## Introduction
GitHub Copilot has expanded its code review support capabilities by making agent skills and MCP servers generally available for a wider range of users. This upgrade extends functionality beyond the initial preview phase.

## What’s New?
Previously in public preview, Copilot's agent skills allow automated review tasks to be carried out by intelligent agents. MCP (Multi-Cloud Platform) servers enable scalable and reliable management of these agents.

## Benefits
By leveraging these features, development teams using Copilot Pro, Pro+, Business, and Enterprise plans can automate repetitive review tasks, maintain higher review quality, and integrate code checks seamlessly within their workflows.

## Conclusion
The general availability of these features signifies GitHub’s continued investment in AI-driven developer tools, enhancing productivity and collaboration for software engineering teams worldwide.
