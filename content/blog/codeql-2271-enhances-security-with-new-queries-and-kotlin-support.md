## What’s New in CodeQL 2.27.1?

The latest release of CodeQL introduces new queries for C, C++, and C#, expanding its static analysis capabilities. This update ensures more comprehensive scanning for vulnerabilities across these widely used languages.

## Kotlin 2.4.20 Support

CodeQL now supports Kotlin version 2.4.20, incorporating the latest language features and syntax enhancements. This broadens the scope of code scanning for teams using Kotlin in their development.

## Improved Query Accuracy

Beyond adding new queries and language support, CodeQL 2.27.1 brings improvements to query accuracy. This results in more reliable identification of potential security risks and coding issues, reducing false positives and enhancing developer confidence.

## Conclusion

Updates like these help integrate security more deeply into the software development lifecycle. By keeping static analysis tools updated, teams can better protect their codebases against emerging threats.
