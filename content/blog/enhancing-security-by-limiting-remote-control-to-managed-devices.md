## Controlling Remote Access in Enterprises

Remote collaboration tools have transformed how teams work, but controlling access remains a critical challenge. Now, enterprises and organizations have a new capability allowing them to restrict which devices can host remotely controlled Copilot sessions.

## Fine-Grained Device Restrictions

This feature grants administrators fine-grained control over device eligibility, ensuring that only authorized, managed devices can initiate or host remote control sessions. It helps reduce security risks associated with unmanaged endpoints.

## Strengthening Remote Work Security

By limiting remote control capabilities to trusted devices, organizations can better protect sensitive data and maintain compliance with corporate IT policies. This enhancement supports a safer and more reliable remote work environment.

## Conclusion

With this update, GitHub empowers organizations to strike a more effective balance between flexibility for remote collaboration and robust security measures.
