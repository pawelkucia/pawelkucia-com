## Introduction
GitHub's AI usage report has evolved to include a detailed per-model token breakdown. This new feature provides transparency on how AI credits are consumed across different models.

## What Does the Breakdown Include?
For each AI model, the report now displays input tokens, output tokens, and cache token data. This granularity aids users in understanding their AI usage patterns better.

## Benefits of Per-Model Transparency
With clear visibility into token usage per model, developers and teams can optimize their AI interactions, manage credit spending more effectively, and make informed decisions on model selection.

## Conclusion
GitHub's updated usage report is a valuable tool for anyone leveraging AI credits, offering detailed insights that promote smarter AI resource management.
